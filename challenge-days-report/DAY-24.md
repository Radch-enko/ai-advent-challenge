# День 24 — Цитаты, источники и антигаллюцинации

## Цель дня

Сделать ответы Copia с включённым RAG проверяемыми: возвращать ответ и подтверждающие его источники с точными цитатами; при отсутствии чанков просить уточнить вопрос.

## Продуктовая реализация в Copia

В настройках сессии пользователь включает `RAG enabled`; там же настраиваются top-K, similarity threshold, query rewrite и reranker. В разделе «Документы» видны папка источников, число Markdown-файлов, настройки эмбеддингов и состояние индекса (`client/src/features/configuration/ui/settingsComponents.tsx:59-65,131-215`; `client/src/features/document-indexing/ui/DocumentsScreen.tsx:105-143,146-245`).

После ответа чата под текстом появляется секция «Источники» с заголовком, разделом, именем файла, `chunk_id` и цитатой. В Task Mode те же поля показываются у вызовов модели; при слабом контексте Task Mode останавливается с видимым состоянием «Нужно уточнение» (`client/src/features/tasks/ui/TaskProgressPanel.tsx:86-107,265-280`).

Если проверка цитаты провалилась и после повтора, Copia показывает последний читаемый ответ с предупреждением «Цитаты не прошли проверку. Ответ модели может быть ошибочным.». Источники остаются только там, где `chunk_id` и цитату можно сопоставить с найденным чанком.

## Техническая реализация

1. При включённом RAG backend передаёт в retriever настройки текущей сессии, получает чанки и добавляет их в системный контекст как недоверенные данные (`src/copia/sessions/api/message_routes.py:371-398`; `src/copia/document_indexing/application/document_retriever.py:63-108`).
2. Для ответа используется structured output со схемой `answer` + `citations`. Ссылка на источник строится backend из retrieval-результата, а не из произвольных метаданных модели (`src/copia/document_indexing/application/rag_citations.py:29-62,117-151`).
3. До отправки ответа в SSE/UI backend проверяет цитаты; в чате `message.delta` отправляется только после проверки или добавления предупреждения (`src/copia/sessions/api/message_routes.py:420-436`). Task Mode использует ту же проверку для плана, сообщений шагов и отчёта (`src/copia/tasks/application/task_workflow.py:101-115,225-237,287-299,382-415`). Внутренняя схема валидации Task Mode не заменена схемой цитирования.
4. Если после similarity-фильтрации не осталось чанков, обычный чат возвращает фиксированное уточнение без вызова генерации ответа. Task Mode останавливает текущий этап и устанавливает `needs_clarification`; завершённые действия не откатываются. При ошибке индекса или провайдера используется ошибка RAG, а не режим «Не знаю».

Ограничения: backend доказывает буквальное совпадение цитаты с чанком и её присутствие в тексте ответа, но не проверяет логическое следование всего ответа из цитаты. Для чанков выше порога решение о достаточности контекста в основном остаётся инструкцией prompt (`src/copia/document_indexing/prompts/rag_context.md:1-5`). Поэтому ручная оценка смысла на реальных ответах остаётся обязательной. При невалидной цитате после повтора ответ всё равно показывается с предупреждением по решению пользователя.

## Сценарий демо

### Подготовка

1. Использовать локальный запуск из `README.md:14-28`: выполнить `./harness/scripts/check-dependencies.sh`, при отсутствии `.env` скопировать `.env.example` и настроить ключ провайдера локально, затем запустить dev-сервисы. Не перезаписывать существующий `.env` и не показывать секреты в кадре.
2. Создать отдельные временные каталоги для синтетических документов и данных, чтобы не читать и не переиндексировать личную базу знаний:

   ```bash
   mkdir -p /tmp/copia-day24-docs
   ```

   Создать в этой папке файл `day24-fictional-facts.md`:

   ```markdown
   # Moon Kiosk
   The Moon Kiosk opens at 06:15 on weekdays.

   # Cloud Tram
   The Cloud Tram stops beside the blue fountain.

   # Archive Door
   The archive door is painted green for the story exercise.

   # Toy Village
   At noon, exactly three small bells ring in the toy village.

   # Glass Garden
   The glass garden grows silver beans in narrow pots.

   # Paper Boat
   The paper boat is kept under the wooden bench.

   # Helper Robot
   The tiny helper robot is named Pipkin.

   # Imaginary Harbor
   The lantern turns on at 19:40 in the imaginary harbor.

   # Paper Train
   The paper train serves cinnamon stars as its evening snack.

   # Library Bridge
   The library bridge is twelve wooden steps long.
   ```

3. Запустить зависимости и API/UI из корня проекта, передав временные пути только процессам Copia:

   ```bash
   COPIA_DATA_ROOT=/tmp/copia-day24-data \
   COPIA_DOCUMENTS_PATH=/tmp/copia-day24-docs \
   ./scripts/restart-dev.sh
   ```

   README указывает UI `http://127.0.0.1:5173` и API `http://127.0.0.1:8000`. Переменная `COPIA_DOCUMENTS_PATH` задаёт папку источников (`src/copia/common/configuration.py:16-17,115-116`). Для демо выбран локальный запуск: `compose.yaml:18-24` монтирует домашний каталог `~/Desktop/CopiaKnowledgeBase`, который может содержать реальные данные.

### Запись

1. Открыть раздел «Документы». Проверить, что показан путь `/tmp/copia-day24-docs` и обнаружен один Markdown-файл. Выбрать настроенного embedding provider/model, нажать «Индексировать» и дождаться состояния завершения.
2. Создать новую чат-сессию с настроенным LLM provider/model. Включить `RAG enabled`; оставить для первого прохода similarity threshold `0.35`, top-K `10`/`3`, query rewrite и reranker выключенными. Настройки RAG доступны в панели параметров сессии (`client/src/features/configuration/ui/settingsComponents.tsx:149-215`).
3. Последовательно задать 10 вопросов:
   - When does the Moon Kiosk open?
   - Where does the Cloud Tram stop?
   - Which color is the archive door?
   - How many bells ring at noon?
   - What grows in the glass garden?
   - Where is the paper boat kept?
   - What is the robot's name?
   - When does the lantern turn on?
   - What snack is served on the train?
   - How long is the library bridge?
4. Для каждого ответа раскрыть «Источники». Сверить `source`, `section`, `chunk_id` с синтетическим файлом; убедиться, что цитата дословно есть в файле и видимом ответе, а формулировка ответа не выходит за смысл цитаты. Записать каждый результат; заранее подготовленные тестовые пары не считать оценкой живой модели.
5. Показать отказ по порогу: для одного поддерживаемого вопроса посмотреть similarity score в сводке выполнения (`client/src/features/chat/ui/ExecutionSummary.tsx:65-66`), поднять порог выше лучшего показанного score, сохранить настройку в этой сессии и повторить вопрос. Ожидаются «Не знаю. Уточните вопрос.» и отсутствие источников. Если не получается создать пустой результат, не подменять наблюдение ожидаемым результатом — зафиксировать фактический ответ.
6. При наличии времени повторить проверку в Task Mode: включить RAG, задать задачу по синтетическим документам, затем проверить источники/цитаты в плане и сообщениях. Для демонстрации `needs_clarification` задать порог выше результата поиска; ожидаются остановка задачи и статус «Нужно уточнение».

## Итог проверки

Статический просмотр текущих изменений подтверждает контракт structured output, backend-проверку цитат, отображение источников в чате и Task Mode, а также режим уточнения при пустом контексте. Фильтрация similarity существовала до Дня 24 и теперь соединена с отказом при пустом результате.

Полное выполнение Дня 24 пока не подтверждено: пользовательская ручная оценка 10 реальных ответов ещё не проведена. В этом отчёте tests, build, серверы и внешние сервисы не запускались; наличие тестов использовано только как evidence coverage. Итоговую отметку о семантической точности следует поставить после ручной записи результатов десяти вопросов.
