# Продуктовое описание Copia

## Суть продукта

Copia — персональный универсальный AI-ассистент, который помогает решать разные личные задачи в одном месте.
Пользователь может выбирать AI-провайдера, создавать специализированных агентов и подключать инструменты, чтобы
ассистент мог не только отвечать на вопросы, но и участвовать в рабочих сценариях.

Сейчас Copia развивается прежде всего для личного использования её автором. Описание продукта не предполагает,
что Copia уже является готовым массовым сервисом.

## Целевая аудитория и ценность

Основной пользователь — автор Copia, которому нужен один настраиваемый помощник для личных сценариев. Ключевая ценность
проекта — постепенно решать больше задач с Copia, используя подходящего агента, AI-провайдера и инструменты.

## Приоритетные сценарии

- Обращаться к специализированному агенту, настроенному на определённую задачу.
- Подключать инструменты к агентам, чтобы получать данные и выполнять действия во внешних системах.
- Автоматизировать повторяющиеся сценарии личной продуктивности, в том числе запускать агентные задачи по расписанию.
- Продолжать работу в сохранённых чатах и настраивать объём контекста и персональной памяти, доступных модели.

## Принципы продукта

- **Выбор провайдера.** Пользователь может выбирать AI-провайдера для поддерживаемых задач, сохраняя работу с агентами и
  инструментами в Copia.
- **Контроль данных.** Данные Copia сохраняются локально по умолчанию. Пользователь выбирает провайдера, которому
  отправляются запросы; обработка переданных ему данных регулируется условиями этого провайдера.
- **Настраиваемая автономность.** Пользователь должен иметь возможность определять, какие действия агенты могут
  выполнять самостоятельно, а какие требуют подтверждения. Точные настройки и уровни риска здесь не специфицируются.
- **Практическая полезность.** Развитие определяется тем, помогают ли агенты и инструменты решать реальные личные задачи.

## Текущее состояние

Ниже перечислены возможности, описанные в текущем README проекта. Это описание существующего поведения, а не обещание,
что оно уже покрывает все продуктовые цели.

- Сохранённые чаты и повторное открытие предыдущих сессий.
- Переиспользуемые профили агентов.
- Настройки контекста, включая сжатие истории, скользящее окно, Sticky Facts и глобальные правила Copia.
- Подключение MCP-серверов и вызов доступных агенту инструментов. Для MCP-действий предусмотрено пользовательское
  одобрение или отклонение.
- Отчёты агентов по расписанию; текущий пример — сводки расходов.
- Отображение использования токенов и оценки заполнения контекстного окна модели.

Хранение пользовательских данных и запросы к моделям — разные аспекты контроля: локальное хранение в Copia не означает,
что запросы к выбранному удалённому AI-провайдеру обрабатываются локально.

## Цели и направления развития

- Сделать специализированных агентов и инструменты центральным способом решать задачи с Copia.
- Расширять полезные инструменты и автоматизации для личной продуктивности.
- Развивать настройки автономности так, чтобы пользователь мог выбирать подходящий уровень контроля действий агента.
- Сохранять контроль пользователя над выбором AI-провайдера и локально хранимыми данными.

Календарные сроки и фиксированный roadmap пока не определены. Приоритет конкретных изменений следует уточнять по мере
появления задач и пользовательского опыта.

## Признак успеха

Copia становится полезнее, если пользователь регулярно решает с её помощью больше разных личных задач. Это основной
качественный ориентир для оценки развития продукта; конкретная числовая цель пока не установлена.
