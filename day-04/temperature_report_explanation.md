```text
**1. Кеш в памяти приложения**
- Это данные, которые лежат прямо в RAM, пока приложение запущено.
- Самый быстрый вариант.
- Подходит для временного хранения: например, уже загруженный список товаров, чтобы не запрашивать его повторно.
- Минус: если приложение закрыли или система его выгрузила — кеш исчезает.

**Пример:** открыл список товаров, вернулся назад и снова вошёл — приложение показывает данные мгновенно из памяти.

**2. Локальная база данных**
- Данные сохраняются на устройстве постоянно.
- Обычно используют SQLite/Room.
- Подходит для офлайн-режима и хранения данных между запусками приложения.
- Медленнее, чем кеш в памяти, но надёжнее.

**Пример:** товары сохранились в базе, и пользователь видит список даже без интернета.

**3. Серверное API**
- Это источник данных на удалённом сервере.
- Приложение отправляет запрос, сервер отвечает JSON-данными.
- Самые актуальные данные, но зависит от интернета и скорости сети.

**Пример:** приложение запрашивает `/products`, получает обновлённые цены и наличие товаров.

**Идея использования:**
API → получить данные, база → сохранить, кеш → быстро показать.
```

```text
1. Сначала смотрим кеш в памяти.

4. Потом обновляем базу и кеш.
```
